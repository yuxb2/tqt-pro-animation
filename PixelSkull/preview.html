PixelSkull

Une tête de mort de seize pixels de côté, agrandie en gros carrés, qui rebondit sur les quatre bords en claquant de la mâchoire. Deux couleurs, pas une de plus. L'écran ci-dessous exécute exactement le code du croquis : mêmes constantes, même dessin, même calage sur la grille.

grille du dessin : ×5  ·  30 images/s

Taille×5
Côté d'un pixel de dessin, en pixels d'écran. Bouton BOOT sur la carte, variante droite dans CyberCycle.
Déplacement
Bouton KEY sur la carte. La dérive suit deux sinus lents, sans impact.
Morsure au mur
Chaque impact remet la mâchoire sur « grand ouvert ».

Va-et-vient gauche-droite.
SPEED_Y15 px/s
Va-et-vient haut-bas. Garde un rapport non entier avec SPEED_X.
Grille
Montre le pas d'agrandissement. Aperçu seulement, pas sur la carte.

Le dessin

Le crâne et la mâchoire sont deux dessins séparés, écrits en binaire dans le croquis : chaque ligne se lit à l'œil, un « 1 » est un pixel d'os. La mâchoire n'est pas articulée — elle descend, d'un nombre entier de pixels. Bouche fermée, les dents du haut et du bas se touchent et n'en font qu'une rangée.

static const uint16_t CRANIUM[13] = {
  0b0000111111110000,
  0b0011111111111100,
  0b0111111111111110,
  0b1111111111111111,
  0b1110011111100111,   // orbites
  0b1100001111000011,
  0b1100001111000011,
  0b1110011111100111,
  0b1111111111111111,
  0b1111111001111111,   // nez
  0b0111110000111110,
  0b0011111111111100,
  0b0010110110110100,   // dents du haut
};
Aperçu à l'ouverture courante. Les trois lignes du bas sont la mâchoire ; l'espace noir au-dessus d'elle est GAP_MAX.

Les réglages du moment

Les valeurs des curseurs, sous la forme qu'elles ont dans le croquis. Dis-moi celles que tu veux garder et je les écris dans PixelSkull.ino.

SCALE_A / _B / _C5 / 4 / 3Les trois tailles que fait passer le bouton BOOT. Toujours entières : c'est ce qui garde les carrés carrés.

          
GAP_MAX3Ouverture maximale. C'est aussi la hauteur réservée en bas de l'écran, pour que le rebond ne change pas de place selon le claquement.
